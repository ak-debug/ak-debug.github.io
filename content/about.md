**I enjoy figuring out how things work — and what happens when they don’t work as expected.**

I’m Akshit Kathuria, a Consulting Engineer at Cisco working across enterprise networking, network validation, security and automation. I enjoy turning complex network scenarios into repeatable tests, troubleshooting failures and understanding how different components interact.

Outside my day-to-day work, I spend time exploring the security questions that make me curious. That’s what this blog is for.

Here I share the labs, CTF challenges and hands-on experiments I work through. I like to go beyond the steps and explain **what I found, why it worked and what I learned along the way**.

Some of the topics you’ll find here:

- **Web security** — exploring vulnerabilities such as XSS, CSRF, SQL injection and access control flaws.
- **Digital forensics and malware analysis** — investigating memory dumps, code injection, hidden data and malware behaviour.
- **CTFs and experiments** — working through web, forensics and steganography challenges.

I hold **CCNP Security**, **Cisco DevNet Associate** and **Cisco Certified Specialist – Securing Networks with Cisco Firewalls** certifications. I’m continuing to build my knowledge of network security, including Cisco Secure Firewall, Cisco ISE and security solution validation.

I’m also interested in how AI can improve engineering workflows. I built [AI Workbench](https://github.com/ak-debug/ai-workbench), an open-source collection of reusable AI agent skills.

Everything on this blog is carried out in isolated lab environments or against deliberately vulnerable, legally provided targets.

You can find more of my code and projects on [GitHub](https://github.com/ak-debug).
