I'm Akshit Kathuria, a security enthusiast focused on offensive security, web exploitation, and malware analysis.

This site is where I write up the labs, CTF challenges, and hands-on experiments I work through, explaining not just the steps but the reasoning behind each one. Topics I spend most of my time on:

- **Web security** — XSS, CSRF, SQL injection, SSRF, and chaining lower-severity bugs into real impact.
- **Digital forensics & malware analysis** — memory forensics with Volatility, identifying code injection, and reverse-engineering trojan behaviour.
- **CTF** — web, forensics, and steganography challenges.

Everything here is carried out in isolated lab environments or against deliberately vulnerable, legally-provided targets.

You can find my code and tools on [GitHub](https://github.com/ak-debug).
